# Dokumentacja projektu

- `PRODUKT.md` – co budujemy i co widzi użytkownik (przy ekranach ma pierwszeństwo).
- `STAN.md` – gdzie jesteśmy: co działa, bieżąca sesja, plan, problemy, decyzje. Zmienia go ostatni prompt sesji.
- `STYL.md` – system stylu „Kalka i korekta”.
- `MASTER_PLAN.md` – plan produktu, dane, architektura, katalog paczek.
- `PLAN.md`, `zadania/` – plan sesji i paczki zadań (do przeglądu pod proces v5).
- `design/` – makiety kluczowych ekranów (wzorzec wyglądu).
- `shots/` – aktualne zrzuty ekranu.
- `sessions/`, `archiwum/` – historia (zakończone zadania i stare plany).
- `data/`, `data-sources.md`, `data-report.md` – materiały o danych GUS.
