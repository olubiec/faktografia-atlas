# Dokumentacja projektu

Ten folder zawiera dokumentację projektu.

- `MASTER_PLAN.md` - główny plan projektu (dodawany przez właściciela).
- `sessions/` - folder zawierający polecenia i podsumowania z poszczególnych sesji (CCx).
- `shots/` - folder na zrzuty ekranu dokumentujące stan po zakończeniu poszczególnych sesji.
