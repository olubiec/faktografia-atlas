# Dokumentacja projektu

- `PRODUKT.md` – co budujemy i co widzi użytkownik (przy ekranach ma pierwszeństwo).
- `STAN.md` – gdzie jesteśmy: co działa, bieżąca sesja, plan, problemy, decyzje. Zmienia go ostatni prompt każdej fali.
- `STYL.md` – system stylu „Kalka i korekta”.
- `ARCHITEKTURA.md` – warstwy W0–W3 i podzespoły, pliki-węzły, dane GUS i kontrakty plików, plan sesji S14–S18 podzielony na fale („co zobaczysz”, założenia, kroki).
- `ELEMENTY.md` – rejestr elementów z zewnątrz: pakiety, dane, zasoby, usługi – źródło, wersja, licencja, atrybucja.
- `prompty/` – gotowe prompty bieżącej sesji (plik usuwa ostatni prompt sesji; historia w gicie).
- `design/` – makiety kluczowych ekranów (wzorzec wyglądu).
- `shots/` – aktualne zrzuty ekranu.
- `data/`, `data-sources.md`, `data-report.md` – materiały o danych GUS.
