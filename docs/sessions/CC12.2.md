Wzorce w zapalne i w zakresie: ** = dowolne katalogi, * = dowolny fragment nazwy, ścieżka z / na końcu = cały katalog. Bez nowych zależności (własne dopasowanie wzorców).
Warunki odbioru:

ID zadania (CC<liczba>(.<część>)*): najpierw z tytułu linkedIssue (gdy treść PR ma Fixes|Closes|Resolves|Zamyka #N), potem z linii Zadanie: <ID> w treści, potem z dowolnego miejsca tytułu PR. Brak ID i brak etykiety sprawdzone → błąd: „Brak ID zadania. Dodaj w opisie PR linię Fixes #<numer issue> albo Zadanie: CCx.y (AGENTS.md, sekcja „Pull request”).”
Zakres = ścieżki w odwrotnych apostrofach z listy pod nagłówkiem Zakres w treści issue (dopiski typu „(nowy)”, „(tylko: …)” są pomijane). Zawsze dozwolone: docs/sessions/<ID>.md. Pliki zrzutów (*-snapshots/) dozwolone, ale z ostrzeżeniem. Plik spoza zakresu albo plik usunięty (status: removed) → błąd z listą plików, chyba że PR ma etykietę sprawdzone.
Plik pasujący do wzorca z zapalne bez etykiety sprawdzone → błąd: „PR zmienia plik zapalny . Potrzebny przegląd Sonneta; po przeglądzie dostanie etykietę sprawdzone.”
Nowy klucz w dependencies albo devDependencies (head względem base) bez etykiety nowa-zaleznosc → błąd z nazwą pakietu; sama zmiana wersji nie jest błędem.
