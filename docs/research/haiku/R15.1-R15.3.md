### Czego nie ustaliłem (R15.3)
- Tabele zgodności MDN dla Geolocation, Service Worker, saveData i prefers-color-scheme nie były w otwartym tekście. Wsparcie na iOS Safari i Chrome Android dla tych API nie jest ustalone.
- Web Share: caniuse nie pokazuje wsparcia dla konkretnych typów plików. Obsługa plików w iOS nie jest potwierdzona osobno. Lista typów pochodzi z MDN i ma charakter ogólny.
- Apple: znalazłem tylko archiwalny przewodnik z 2016 roku. Nowsze dokumenty Apple dotyczą przeglądarek z własnym silnikiem (BrowserEngineKit) i nie opisują Safari, więc ich nie wykorzystałem.
- Zalecane wzorce pytania o zgodę na lokalizację: w otwartych źródłach nie znalazłem. Nie podaję ich.
- Workbox: rozmiar paczki, bieżąca wersja, strategie cache oraz data ostatniego commita nie są ustalone. Dokumentacja developer.chrome.com nie była otwarta.
- Kryteria instalacji dla Chrome Android (WebAPK) oparte są na stronach MDN i web.dev. Nie sprawdzałem ich na urządzeniu.
- Nie sprawdzałem kryteriów instalacji dla iOS 16.3 i wcześniejszych w oficjalnym źródle. MDN wspomina o nich tylko ogólnie.
