## Wnioski
1. Geometria (`trend-geometry.ts`) wystarcza bez zmian. Brakuje: serii roczna jednej jednostki z przerwą dla brakujących lat, mediany kraju, tooltipu tekstowego, przeciągania, wspólnego stanu roku.
2. Dwie luki do naprawy w specyfikacji: (a) lata nieobecne w osi (2015 w `preschool-3-6`) dziś łączą linię – seria musi dopisać `null` dla każdego roku między min a max; (b) 1 punkt dziś = komunikat – wykres lat ma pokazać sam punkt.
3. Rozkład lat: 16 z 20 wskaźników ma 22–31 lat (potrzebna etykieta co kilka lat, `getXAxisYears` już to robi), `median-age` ma 4 lata (jedna siatka, bez kłopotu). Pełnej biblioteki nie policzono; fixture ma 2–3 lata, więc przypadek 2–3 lat musi działać.
4. Tooltip i stan roku muszą iść przez props z `AtlasMap`/`useMainView`. Własny `useState` z `TrendChart.tsx:31` zostaje tylko w profilu do czasu QU26.
5. Kod `TrendChart` ma wartości na sztywno, więc nie nadaje się do skopiowania 1:1. Nowy komponent bierze rozmiary z tokenów.

## Rekomendacja
Wariant A, nowe pliki, `TrendChart` bez zmian (profil przepina się dopiero w QU26).

**API (nazwy zgodne z kodem: `TrendDataPoint`, `IndicatorValues`, `UnitLevel`, `formatValue`)**
```ts
// src/core/charts/year-series.ts – czysta funkcja, komentarze po polsku
export type YearSeries = { id: string; label: string; points: TrendDataPoint[] }; // points co rok, brak = null
export function buildYearSeries(values: IndicatorValues, teryt: string): TrendDataPoint[];
export function buildMedianSeries(values: IndicatorValues, teryts: string[]): TrendDataPoint[]; // mediana kraju na poziomie
export function densifyYears(points: TrendDataPoint[]): TrendDataPoint[]; // dopisuje null dla lat spoza osi
export function nearestYear(points: TrendDataPoint[], x: number, xOf: (y: number) => number): number | null;
export function describePoint(series: YearSeries[], year: number, unit?: string): string[]; // tekst tooltipu
```
```ts
// src/view/charts/YearLineChart.tsx
type YearLineChartProps = {
  series: YearSeries[];            // [jednostka, mediana, (druga jednostka)]
  year: number;                    // ze stanu roku (useMainView), nie z useState
  onYearChange: (year: number) => void;
  unit?: string; label: string;    // jak w TrendChartProps
  height?: number;                 // z tokena, domyślnie jak w kontekście (panel/profil/okno)
  variant?: 'panel' | 'profile' | 'share' | 'compare';
};
```
**Interakcja (390 i 1280 px)**
- Jedno źródło roku: `year` + `onYearChange`. Suwak roku i punkt na linii zsynchronizowane. Przeciągnięcie po linii (`pointermove`/`pointerdown`, `touch-action: pan-y`) wybiera najbliższy rok z danymi.
- Najechanie (1280) i dotyk (390) pokazują tooltip: rok, wartość jednostki z `formatValue`, wartość mediany, druga jednostka. Czysty tekst w SVG/React, bez HTML. Tooltip nie wychodzi poza pole (przycięcie jak `label()` w `card-trend.ts:69-73`).
- Linie: wybrana jednostka (`tusz`, grubsza), mediana kraju (`olowek`, przerywana), druga jednostka w Porównaj (`korekta`).
- Klawiatura: fokus na wykresie, ←/→ ±1 rok bez zawijania, Home/End (jak `TrendChart.tsx:77-92`, zawijanie do zbadania w QU13). Komunikat dla czytnika w `role="status"`.
- Cel dotykowy ≥ 44 px (kolumna jak `TrendChart.tsx:126`). Animacje (przejście punktu) wyłączone przy `prefers-reduced-motion`. Kolory, rozmiary, promienie z tokenów, bez liczb wpisanych na sztywno.
- Braki: `null` przerywa linię, brakujący rok dostaje `null` (`densifyYears`). 1–2 lata: sam punkt / krótki odcinek, bez komunikatu „za mało danych”. Brak każdego punktu: napis „brak danych”.
