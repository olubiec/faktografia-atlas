# QU22 – Moje wskaźniki / wskaźnik mapy / zestaw kart · warstwa „Przewiń w dół” · pasek stron
Stan: origin/main (ostatni commit 2026-11-20). Tylko analiza kodu; aplikacji nie uruchamiano (patrz „Nie odtworzono”).

## Fakty
**A. Trzy źródła stanu (uwaga 12)**
- F1. Wskaźnik mapy = `useMainView`: adres `?i=` → `indicator` (useMainView.ts:38,53-56); `setIndicator` zapisuje adres i zeruje rok (:73-76). Nie zna listy „Moje”.
- F2. Lista „Moje” = `useMyIndicators` (useMyIndicators.ts:22-75), zapis w localStorage + zdarzenie okna (:32-34); `add/remove/reset/move` (:59-72). Nie zna widoku mapy.
- F3. Zestaw kart = `Deck` w `useState` okna (ShareDialog.tsx:71-74), tworzony raz przy otwarciu przez `initialDeck` (useShareData.ts:236-245). Okno jest montowane tylko na czas otwarcia (LazyShareDialog.tsx:7), więc każde otwarcie = nowy zestaw.
- F4. `DeckPage.indicatorIds` (deck.ts:6) jest zapisywane (useShareData.ts:238-243; ShareDialog.tsx:192) i nigdy NIE czytane przy rysowaniu: `dataForPage` zwraca `data[kind]` (useShareData.ts:268-273), a `activeCardData` bierze je stąd (ShareDialog.tsx:100-110). Funkcje `addIndicatorToPage/removeIndicatorFromPage/replaceIndicator` (deck-page-data.ts:24-40) nie mają żadnego wywołania w `src/` (grep).
- F5. Droga „panel mapy” (IndicatorPanel.tsx:63,174; MobileIndicatorBar.tsx:97,178): karty Mapa i Ranking = wskaźnik mapy (useShareData.ts:117-182). Profil: lista = „Moje” + bieżący (useShareData.ts:185-189), karta „inne” = max 5 z tej listy poza bieżącym (:200-207), CSV profilu tylko wiersze z „Moich” (:192).
- F6. Droga „profil miejsca” (Chorzów, uwaga 12): ProfileOverview.tsx:163-207 buduje `ShareDialogData` sam, bez `useShareData`: `bigNumber` i `indicatorName` = wskaźnik mapy (:179-182; tu saldo migracji), „inne” = pierwsze 5 z `profile.indicators` w kolejności katalogu (:166-169). `profile` pochodzi z całego `config/indicators.json` (useProfile.ts:6-8,44), nie z „Moich”. `unitProfile: profile` (:206) → CSV pełny profil (useShareData.ts:280-282). Brak `data.indicator`, więc `activeId` w `initialDeck` = null i strona Profil dostaje `mine.slice(0,20)` (deck-page-data.ts:49-50) – nieużywane przy rysowaniu (F4).
- F7. „+ Dodaj stronę” kopiuje `indicatorIds` bieżącej strony (ShareDialog.tsx:191-196), nie podpowiada z „Moich”; menu ogranicza rodzaje do `availableKinds` (AddPageMenu.tsx:40; ShareDialog.tsx:60-69,261).
- F8. Dodanie w „Moich” przełącza wskaźnik mapy (MobileIndicatorBar.tsx:48 `onAdd → add(id); onPick(id)`). Usunięcie bieżącego z „Moich” go nie zmienia: lista wyboru dokłada bieżący (IndicatorPanel.tsx:56-59). Wiersze „Moich” nic nie robią po kliknięciu nazwy (MyIndicatorsBar.tsx:24-26,56).
- F9. Zmiana roku/poziomu/jednostki przy otwartym oknie: okno jest modalne, więc w praktyce brak; po zamknięciu i otwarciu zestaw startuje od nowa (F3). `data` jest żywe (karty biorą `data` na bieżąco, ShareDialog.tsx:100-110), `deck` nie.
