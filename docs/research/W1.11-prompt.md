# W1.11 – prompt do Gemini Deep Research (wklej w aplikacji Gemini z włączonym Deep Research)

```text
Zrób głęboki research (Deep Research).
Temat: dane GUS BDL (Bank Danych Lokalnych) dla gmin miejsko-wiejskich w Polsce – czy da się je rozdzielić na część miejską i wiejską.
Decyzja, którą ma wesprzeć: czy w atlasie można pokazać osobno „miasto” i „obszar wiejski” gminy miejsko-wiejskiej (kody TERYT z końcówką 4 – gmina miejska części, 5 – obszar wiejski części) i dla których wskaźników.
Kontekst projektu: publiczna strona z mapą Polski (województwo > powiat > gmina > miejscowość), dane wyłącznie z GUS BDL pobierane robotem w GitHub Actions do plików JSON; 20 wskaźników (m.in. ludność, bezrobocie, wynagrodzenia, mieszkania, dochody gmin); projekt niekomercyjny; liczby tylko z BDL.
Zakres: struktura TERYT gmin miejsko-wiejskich (rodzaj 3 i jednostki 4/5), czy BDL udostępnia dla nich osobne wartości (API BDL, poziom 6 i 7?), lista wskaźników z takimi danymi, przykłady zapytań do API (adres i parametry), ograniczenia (lata, brak danych, tajemnica statystyczna).
Poza zakresem: dane spoza GUS, projektowanie interfejsu.
Rodzaj: [C] technologia / dane

Wymagania wobec wyniku:
- tabela: wskaźnik · czy jest osobno dla miasta i wsi · poziom/identyfikator w API BDL · od którego roku · uwagi,
- każde twierdzenie z linkiem do źródła pierwotnego (dokumentacja API BDL, strona GUS). Bez linku napisz „niezweryfikowane”,
- oddziel fakty od opinii; przy faktach podaj datę („stan na …”),
- nie wymyślaj identyfikatorów, nazw wskaźników, adresów API ani liczb; jeśli nie jesteś pewien, napisz to,
- na końcu: rekomendacja (robimy / nie robimy / robimy dla wybranych wskaźników), 3 największe ryzyka i lista rzeczy, których nie udało się ustalić,
- po polsku, prosto; długość: tabela + maks. 2 strony tekstu.
```
